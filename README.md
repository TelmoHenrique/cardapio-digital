# Cardápio Digital

Projeto pronto para publicar na Vercel.

## Como rodar localmente (opcional)
```
npm install
npm run dev
```

## Como publicar (Vercel + GitHub)
1. Crie um repositório novo no GitHub e suba todos estes arquivos.
2. Na Vercel, clique em "Add New Project" e importe esse repositório.
3. Framework Preset: Vite (a Vercel detecta automaticamente).
4. Clique em Deploy.

Pronto — a Vercel gera uma URL pública tipo `seu-projeto.vercel.app`.
